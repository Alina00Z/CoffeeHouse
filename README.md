# CoffeeHouse

Frontend-приложение кофейни, разработанное по [дизайн-макету из Figma](https://www.figma.com/design/oPN8KkgxOL3sHQBI4kuhYf/Coffee-House?m=auto&t=jtLJVm6WZEdIPFKF-6)

Проект реализован с использованием Vue.js и Nuxt.js. Основная задача — преобразовать готовый UI/UX дизайн в адаптивное веб-приложение с интерактивными компонентами.

## 📌 О проекте

Проект выполнен в рамках frontend-разработки:
- реализация дизайна из Figma
- создание компонентной архитектуры
- разработка адаптивного интерфейса
- добавление пользовательских взаимодействий.

## ✨ Реализовано

### Основные элементы

- Главная страница кофейни
- Страница меню
- Карточки товаров по категориям
- Модальное окно с подробной информацией о товаре
- Кастомный слайдер
- Бургер-меню
- Адаптивное меню для мобильных устройств
- Адаптивная верстка под разные разрешения экрана.

### Интерактивность

- переключение категорий меню
- открытие модального окна с карточкой товара
- закрытие модального окна по кнопке и backdrop
- блокировка прокрутки страницы при открытом меню или модальном окне

## Реализация в коде

### Меню товаров

Меню реализовано через массивы данных внутри `pages/menu.vue`.
Для каждой карточки передаются название, описание, цена и категория товара. Карточки отрисовываются через компонент `CoffeeMenuCard.vue` с помощью `v-for`.
Переключение категорий работает через состояние `tabsState`: при выборе вкладки активируется нужная категория, а остальные скрываются через условный рендеринг `v-if`.

### Компоненты

Интерфейс собран из 7 Vue-компонентов:

- `Header.vue` — шапка сайта, навигация и кнопка меню
- `Burger.vue` — мобильное бургер-меню
- `Footer.vue` — футер с контактами и социальными ссылками
- `Slider.vue` — слайдер популярных кофейных напитков
- `CoffeeMenuCard.vue` — карточка товара
- `ModalCard.vue` — модальное окно товара
- `BoxImage.vue` — компонент изображения для галереи

### Слайдер

Слайдер реализован в компоненте `Slider.vue`.

Он содержит 3 слайда с кофейными напитками. Переключение работает через состояние `number_active_slider`, а отображение нужного слайда меняется с помощью CSS-классов `active-1`, `active-2` и `active-3`.

Для управления добавлены кнопки перехода к следующему и предыдущему слайду.

### Модальное окно товара

При клике по карточке товара компонент `CoffeeMenuCard.vue` отправляет событие `click-card`.

В `layouts/default.vue` это событие обрабатывается через `$nuxt.$on`. После выбора товара открывается компонент `ModalCard.vue`, которому передаются данные карточки: тип, название, описание и цена.

При открытии модального окна:

- появляется backdrop
- блокируется прокрутка страницы
- отображается подробная информация о товаре
- показываются варианты размера и добавок
- окно можно закрыть кнопкой `Close` или кликом по backdrop

### Layout

Общий layout находится в `layouts/default.vue`.

В нём подключены:

- header
- основной контент страницы через `<Nuxt />`
- footer
- модальное окно товара
- backdrop для затемнения страницы

### Адаптивность

Адаптивность реализована через медиазапросы в `assets/main.css` и стилях отдельных компонентов.

На мобильных разрешениях:

- основная навигация скрывается
- появляется бургер-меню
- меняется размер слайдера
- перестраивается галерея изображений
- модальное окно адаптируется под ширину экрана
- карточки меню выстраиваются удобнее для просмотра на мобильных устройствах

## Архитектура проекта

Использована компонентная структура Nuxt:

- `pages` — страницы приложения
- `components` — переиспользуемые UI-компоненты
- `layouts` — общий каркас приложения
- `assets` — стили и статические ресурсы.

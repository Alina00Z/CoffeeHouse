# CoffeeHouse

Frontend-приложение кофейни, разработанное по [дизайн-макету из Figma](https://www.figma.com/design/oPN8KkgxOL3sHQBI4kuhYf/Coffee-House?m=auto&t=jtLJVm6WZEdIPFKF-6)

Проект реализован с использованием Vue.js и Nuxt.js. Основная задача — преобразовать готовый UI/UX дизайн в адаптивное веб-приложение с интерактивными компонентами.

## 📌 О проекте

Проект выполнен в рамках frontend-разработки:
- реализация дизайна из Figma
- создание компонентной архитектуры
- разработка адаптивного интерфейса
- добавление пользовательских взаимодействий.

## ✨ Реализовано

- Главная страница кофейни
- Страница меню
- Карточки товаров
- Модальное окно с подробной информацией о напитке
- Кастомный слайдер кофе
- Адаптивное меню для мобильных устройств
- Адаптивная верстка под разные разрешения экрана.

## Технологии

- Vue.js 2
- Nuxt.js 2
- JavaScript
- HTML5
- CSS3
- Git

## Архитектура проекта

Использована компонентная структура Nuxt:

- `pages` — страницы приложения
- `components` — переиспользуемые UI-компоненты
- `layouts` — общий каркас приложения
- `assets` — стили и статические ресурсы.
